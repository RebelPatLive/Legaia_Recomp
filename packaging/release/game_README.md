# Game folder

Put your own copy of **Legend of Legaia (USA, SCUS-94254)** here:

- the `.cue` file, and
- the `.bin` file(s) it points to (same folder, same names the `.cue` expects).

Then start the game and pick the `.cue` file when the launcher asks for your disc.
The launcher accepts a disc from any location, so this folder is just a tidy
place to keep it.

This project does **not** include the game. You must supply your own legally
purchased copy.
